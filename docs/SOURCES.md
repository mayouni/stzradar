# Sources

Where the weekly survey looks. The desk keeps this list current: a source that has stopped earning its place is
removed with a line saying why, and a new one is added once it has given an entry worth keeping.

**Seeded on 2026-11-08 and confirmed by the first survey the same day (2026-W45).** What each address gave is noted
beside it. A source the desk could not read is kept, with the reason, until a later run finds a way or removes it.

## Papers

- arXiv listings: [cs.AI](https://arxiv.org/list/cs.AI/recent), [cs.CL](https://arxiv.org/list/cs.CL/recent),
  [cs.SE](https://arxiv.org/list/cs.SE/recent), [cs.CR](https://arxiv.org/list/cs.CR/recent), [cs.PL](https://arxiv.org/list/cs.PL/recent)
- [Hugging Face daily papers](https://huggingface.co/papers). Its week view runs Saturday to Friday, not the ISO
  week, so it is read by day.

## Labs and tool makers

- [Anthropic news](https://www.anthropic.com/news)
- [OpenAI news](https://openai.com/news): refused automated reading on 2026-11-08 (HTTP 403); to be read in a browser
- [Google DeepMind blog](https://deepmind.google/blog/); some of its posts live on [Google's blog](https://blog.google/)
- [Meta AI blog](https://ai.meta.com/blog/), [Mistral AI news](https://mistral.ai/news)
- Qwen: the old blog points to [qwen.ai/research](https://qwen.ai/research), which shows nothing without a browser
- DeepSeek: news is listed in the sidebar of [its API documentation](https://api-docs.deepseek.com/), not at `/news/`
- Coding agents: [Claude Code changelog](https://raw.githubusercontent.com/anthropics/claude-code/refs/heads/main/CHANGELOG.md)
  (read the raw file; it carries no dates), [OpenAI Codex releases](https://github.com/openai/codex/releases),
  [GitHub changelog](https://github.blog/changelog/), [Cursor changelog](https://cursor.com/changelog)

## Security

- [GitHub Security Advisories](https://github.com/advisories)
- [OWASP GenAI Security Project](https://genai.owasp.org/) (the Top 10 for LLM and agent applications)
- Advisories for agent tool protocols, model hubs, and package registries: the MCP SDKs'
  [TypeScript](https://github.com/modelcontextprotocol/typescript-sdk/security/advisories) and
  [Python](https://github.com/modelcontextprotocol/python-sdk/security/advisories) advisories, and the
  [specification](https://modelcontextprotocol.io/llms.txt), whose index lists every revision
- Security companies' research posts often refuse automated reading; read them in a browser (Apiiro, 2026-11-08)

## Practice, regulation and standards

- [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework)
- The European Union's AI Act: [the Commission's page](https://digital-strategy.ec.europa.eu/en/policies/regulatory-framework-ai),
  which carries the current application dates
- Independent writers who test what they report, for example [Simon Willison's weblog](https://simonwillison.net/)
