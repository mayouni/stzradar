# Schedule

The weekly survey (`docs/WEEKLY.md`) runs on the author's word. This file records what the author ruled, and when.

    schedule:  not set -- owed to the author: day and hour of the weekly run
    publish:   not ruled -- owed to the author: may a scheduled run push to origin, or does it stop at a local commit?

Until both lines are ruled, the survey runs only in an attended session, when the author asks for it.
