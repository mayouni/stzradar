## What happened

OpenAI and Cisco introduced Shirudo on November 23, 2026: an open-source runtime that protects a running Linux system
in the time between a published flaw and its fix. The name is Japanese for shield.

- **What a protection is.** The project calls it an upatch: a signed eBPF loader that creates its maps and loads its
  programs from inside the kernel. Its hooks include BPF LSM, fentry and fexit, fmod_ret, uprobes and uretprobes, XDP
  and raw tracepoints. Java protections are checked in user space.
- **Who may load one.** Each upatch carries a detached ML-DSA-87 signature, which the kernel checks against its sealed
  `.bpf` keyring before loading. Root without the key cannot prepare a load.
- **What is recorded.** Every change to the loaded set extends a per-boot TPM 2.0 register; `shirudo attest` returns
  evidence that can be verified offline.
- **Who writes them.** The documentation says engineers and agents can read, generate and maintain upatches. In
  OpenAI's controlled test, a protection generated by Codex added an input check to Java's Base64 decoder and blocked
  an exploit attempt against a running Elasticsearch service, with no restart.

The licence is BSD 2-Clause, with the BPF programs dual-licensed BSD and GPL. The project describes itself as
pre-release: production needs a kernel with its signed-loader ABI and its kernel patches, plus a TPM 2.0; unloading
runs in user space; and it names a kernel flaw as able to bypass every check. Its continuous integration runs on
x86-64 and arm64.

## Why it matters to Softanza

Harobanda declares the machine an application runs on and pins its kernel by version; a published flaw that reaches a
pinned kernel waits for the next pin. Shirudo is a way to cover that wait with a narrow program, signed, loaded into
the running machine and recorded in its TPM, which matches Harobanda's habit of declaring and recording what runs.
It also shows an agent writing the protection, checked by a signature it cannot produce itself. Its price is a
patched kernel with a sealed keyring, which Harobanda can weigh at its next pin.
