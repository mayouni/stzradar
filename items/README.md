# Entries

One file per entry, in a folder per year: `items/<year>/<id>.md`. Each file opens with a JSON block, which is the
entry's data, followed by its narrative: what happened, why it matters to Softanza, what we do, and the sources.
The method is [`docs/METHOD.md`](../docs/METHOD.md) and every field is described in [`docs/FEED.md`](../docs/FEED.md).
